# API Documentation

> リポジトリ `local-sights` の外部・内部 API 面。2026-10-12 の全体スキャン（コミット `9d08cbf`）に基づく。HTTP の公開エンドポイントは存在しない（サーバーを持たないデスクトップアプリ）。

## 1. Tauri コマンド（画面 → アプリ、内部 IPC）

定義: `src-tauri/src/lib.rs`（`#[tauri::command]` と `invoke_handler`）。宣言: `src-tauri/build.rs`、`src-tauri/capabilities/default.json`、`src-tauri/permissions/autogenerated/`。呼び出し側のラッパー: `src/api.ts`。合計 25 個。引数は camelCase の JSON、エラーは `CommandError { key }`（文言カタログのキー）。状態を変えるコマンドは原則 `void` を返し、結果は `session-changed` イベントで届く。

## 2. Tauri イベント（アプリ → 画面）

| イベント | ペイロード | 送出タイミング |
|---|---|---|
| `session-changed` | `SessionView` 全体 | 状態が変わるたび |
| `fetch-progress` | `FetchProgressUpdate`（jobId、進捗、件数、timelineVersion、フィルタ要約、cacheSaving） | 取得中の一覧ページ・追加ページごと（全体ビューより軽い） |
| `filter-progress` | `FilterProgressUpdate`（フィルタ要約、resultVersion） | フィルタ走査中と完了時 |

主な型（`src/api.ts` / `session.rs`）: `SessionView`（phase、入力、検証エラー、接続、ロググループ一覧、進捗、失敗ストリーム、フィルタ、キャッシュ、終了確認、`ssoLogin`）、`DisplayRow`、`RowWindow`、`RowPositions`、`ApiFailure { kind, safeDetail, retryable }`、`FailureKind`（`AuthRequired`、`AccessDenied`、`Throttled`、`Network`、`NotFound`、`InvalidInput`、`RegionMissing`、`Other`）。

## 3. `CloudWatchLogsGateway` trait（AWS 境界、内部）

`crates/local-sights-core/src/gateway/mod.rs`。AWS に触れる唯一の境界で、読み取り 3 操作しか持たない。実装は `gateway/aws.rs`（`AwsCloudWatchLogsGateway`）、テストは `tests/support/fake_gateway.rs`。

```rust
pub trait CloudWatchLogsGateway: Send + Sync {
    fn get_log_events(&self, request: GetLogEventsRequest)
        -> impl Future<Output = Result<GetLogEventsPage, ApiFailure>> + Send;
    fn describe_log_groups(&self, request: DescribeLogGroupsRequest)
        -> impl Future<Output = Result<DescribeLogGroupsPage, ApiFailure>> + Send;
    fn describe_log_streams(&self, request: DescribeLogStreamsRequest)
        -> impl Future<Output = Result<DescribeLogStreamsPage, ApiFailure>> + Send;
}
```

- `GetLogEventsRequest`: `profile_name`、`region`、`log_group_name`、`log_stream_name`、`start_time`（含む）、`end_time`（含まない）、`start_from_head`、`next_token`。ページ終端は「送った forward token と同じ token が返る」で判定（`paging.rs`）。
- `DescribeLogGroupsRequest`: `next_token` だけを API に渡し、絞り込みは取得後に行う。
- `DescribeLogStreamsRequest`: 最終イベント時刻の新しい順で読む。名前の prefix は渡さない。
- 接続先の解決: 指定リージョン → プロファイルの既定リージョン → 無ければ `RegionMissing` を API を呼ばずに返す。

### 他の内部 trait 境界

| trait | 場所 | 役割 |
|---|---|---|
| `FetchSink` | `coordinator.rs` | 取得の進行通知（`on_started`、`on_listing_progress`、`on_planned`、`on_batch`、`on_stream_finished`、`on_saving`、`on_finished`）。Tauri は `TauriSink`、例は標準出力、テストは `RecordingSink` |
| `TimelineStore` | `coordinator.rs` / `log_view.rs` | ページの追加先。`LogView` が実装し追加時にフィルタ判定も行う |
| `ListingSink` | `log_groups/listing.rs` | ロググループ一覧のページ通知 |
| `TimeZoneContext` | `time_zone.rs` | 「Local」が指す IANA ゾーン。テストは固定ゾーンに差し替え |

## 5. ファイル／OS との境界

| 境界 | 場所 | 読む／書く内容 |
|---|---|---|
| `~/.aws/config`、`~/.aws/credentials`（`AWS_CONFIG_FILE` / `AWS_SHARED_CREDENTIALS_FILE` 優先） | `catalog/files.rs` | セクション名、`region`、`sso_session` / `sso_start_url` の有無、`source_profile` の名前。値は捨てる。読み取り専用 |

## 7. ビルド・配布面で読まれる設定（本インテントに関係）

- `src-tauri/tauri.conf.json`: `productName: "Local Sights"`（`.app` 名）、`identifier: "dev.local-sights.app"`、`bundle.active: true`、`bundle.targets: "all"`、`bundle.icon`（6 ファイル）。**`bundle.macOS` 節（`signingIdentity`、`minimumSystemVersion`、`entitlements`）は無い**ため、Tauri CLI の macOS 署名は環境変数 `APPLE_SIGNING_IDENTITY` の有無だけで決まる。未設定なら署名せず、`"-"` ならアドホック署名、Developer ID 名なら本署名。
- `.github/workflows/release.yml` の `build-and-publish` ジョブ: `npm run tauri build -- --bundles dmg`（環境変数なし）→ `target/release/bundle/dmg/*.dmg` を 1 つ確認 → `Local-Sights_<ver>_aarch64.dmg` にコピー → `gh release create`。`release-dry-run.yml` は同じビルドステップで公開せず artifact にする。
