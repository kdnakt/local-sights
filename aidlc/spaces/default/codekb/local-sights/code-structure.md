## コードの決まりごと（読み取れたもの）

- **説明の書き方**：Rust は `#![warn(missing_docs)]` で、モジュールと公開項目すべてに説明がある。説明には業務ルールの番号（`U5:BR1.2`、`FR6.2`、`review R-02` など）と、どの intent で入ったか（`Since 261012-parallel-fetch U5`）が残っている。
- **純粋な判断と流れの分離**：判断は副作用の無い関数や型（`streams/mod.rs`、`schedule.rs`、`cache/plan.rs`、`sso_login.rs`、`filter.rs`）に置き、I/O と待ちは流れの側（`streams/planner.rs`、`coordinator.rs`、`cache/mod.rs`、`src-tauri`）に置く。
- **境界の trait**：AWS は `CloudWatchLogsGateway`、取得の受け口は `FetchSink`、保持先は `TimelineStore`／`HeldEvents`。テストは偽物に差し替える（`tests/support/fake_gateway.rs`、`recording_sink.rs`）。
- **ロックの順番**：常にセッション → LogView（→ 停止の取っ手）。取得は 1 ページごと、走査は 1 かたまり（4,096 件）ごとにロックを取って離す。毒されたロックは `unwrap_or_else(PoisonError::into_inner)` で回復する。
- **版で順番を守る**：`timelineVersion`、`filterResultVersion`、`discardGeneration`、`connectionGeneration`。画面は古い応答を捨てる。
- **エラー処理**：テスト以外で `unwrap()`／`expect()` を使わない（team.md）。画面へのエラーは文言キー（`message_key()`）で返す。
- **OS ごとの処理**：`cfg(unix)`／`cfg(windows)` は `sso_cli/`、`browser.rs`、`cache/mod.rs`（フォルダ 0700・ファイル 0600 は Unix だけ）、`cache/settings.rs`、`lib.rs` の `cfg(target_os = "macos")`（アプリメニュー）に限られる。
- **命名**：Rust は snake_case／UpperCamelCase、TypeScript は camelCase。Rust 側の型は `serde(rename_all = "camelCase")` で画面の型と名前をそろえる。
