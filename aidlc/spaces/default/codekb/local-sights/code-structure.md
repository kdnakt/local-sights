## アプリ（`src-tauri/src/`）

`lib.rs` は 1 ファイルに、定数（`SCAN_CHUNK_ROWS = 4_096`、`MAX_ROWS_PER_REQUEST = 1_000`、`QUERY_PROGRESS_INTERVAL = 250 ms`、`SETTINGS_FILE_NAME`、`CACHE_FOLDER_NAME`）、`AppState`（`AppSession`・`LogView`・`QueryStore`・ゲートウェイ・止める合図・SSO の制御を `Mutex` / `Arc` で持つ）、`CommandError`（中核のメッセージ鍵を画面へ）、`lock` / `emit_or_log` / `drop_if_stale` の補助、32 個の `#[tauri::command]`（384〜1530 行）、取得・クエリ・絞り込みを `tokio::spawn` / `spawn_blocking` で始める関数、`TauriListingSink` / `TauriSink` / `TauriQuerySink`（1664〜1884 行）、メニュー（Quit）と閉じる確認、`run()` の起動（`setup` で起動時の一覧）を持つ。テストは `#[cfg(test)]` に 2238 行以降。

`sso_cli/mod.rs` は決め事（候補パス、5 分の時間切れ、2 秒の猶予、行の読み）を持ち、`unix.rs` / `windows.rs` が OS の 3 関数を提供する。`browser.rs` は `cfg` で 2 つの `open_url`。

## 画面（`src/`）

`main.tsx` が `App` を描き、`App.tsx` が 1 つの窓を組み立てる（`AppNavigation`、`TopBar`、`LogGroupPane` ＋ `PaneResizer`、`ConditionArea`、`FetchErrorBanner` / `CancelNotice` / `FailureList`、`LogTable` か `LogTableCloudscape`、`StatusLine`、`LogAnalyticsPage`、4 つのダイアログ、`SsoLoginModal`）。`api.ts` が Tauri の型と `invoke` の関数、イベントの購読、部分更新の合成を持つ。`components/` は 1 部品 1 ファイルで、同名の `.test.tsx` が隣にある。`hooks/` は開いた行の状態（`expansionState.ts`、純粋な関数）、ペインの幅（`localStorage`）、色の様式、デバウンス、Escape、初回フォーカス、行の配置と窓。`i18n/messages.ts` は `messages` の表（`en` / `ja`）、`detectLocale`、`translate`（`{name}` の置き換えだけ）、`createTranslator`。

## コードの決まりごと（読み取れたもの）

- **文書化**：中核は `#![warn(missing_docs)]`。モジュールの先頭と公開項目に説明があり、要件の ID（`U3:BR1.2`、`NFR4.2`、`review R-03`）と作業の名前（`261012-parallel-fetch U5`）を引く。画面の部品も先頭に役割を書く。
- **エラー**：本番コードは `Result` で返す。`Mutex` は `unwrap_or_else(PoisonError::into_inner)`（`lib.rs:354`）。`unwrap()` / `expect()` はテストと `tests/support/` に限る（`fake_gateway.rs:293-297` の `expect` が本作業の (1) の落ち方）。
- **OS 依存**：`cfg(unix)` / `cfg(windows)` は `sso_cli/`、`browser.rs`、`cache/mod.rs` のパーミッション、`main.rs` の `windows_subsystem` に限る。
- **秘密の扱い**：`failure.rs` がアクセスキーらしい文字を `[REDACTED]` にし、`sso_cli` は URL とコード以外の出力を捨てる。ログの中身は `compat` の報告でも 40 文字に切る。
- **名前**：Rust は snake_case / UpperCamelCase / SCREAMING_SNAKE_CASE、TypeScript は camelCase、JSON は `camelCase`（`serde(rename_all)`）。テスト名は英語の文（`a_cancel_during_the_cache_lookup_completes_a_hit_and_cancels_a_miss`）。
- **登録の一致**：コマンドは 3 か所で同じ集合（Rust と TS の両方のテストで守る）。
- **整形**：rustfmt、Prettier（printWidth 100、trailingComma all）、LF 固定。
