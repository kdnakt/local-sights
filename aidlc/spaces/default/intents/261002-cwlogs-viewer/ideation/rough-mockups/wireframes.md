## 前提

- デスクトップ GUI アプリ（Q1）。MVP の対応 OS は macOS のみで、Windows は MVP 後（Q8。Q2 を置き換え）。利用者の見解として、後からの OS 対応はクロスプラットフォームの仕組みを使えば容易と考えている（Q8。具体的な技術選定は開発ルール確認以降で行う）。
- 1 画面にすべてを並べる（Q3）。
- 見た目は最小限：OS 標準の部品だけを使い、ブランドやデザインシステムの指定はない（Q7）。最小ウィンドウサイズ、ログ表の列幅、高解像度ディスプレイ、ダークモードの扱いは要件分析で決める。
- 画面に載せる機能は MVP の範囲（scope-document、intent-backlog の IB-01〜IB-06）に限る。進捗表示・中断・ファイル書き出し・JSON 整形は MVP 後（intent-backlog の IB-08〜IB-10）なので、ここには描かない。
- 図は英語の仮ラベルで描いている。画面の表示言語は要件分析で決める。

## 期限と削減順

- 「GUI・macOS のみ・見た目最小限で 1 週間以内に作れる」は、まだ根拠のある見積もりではなく**仮説**である（feasibility の RAID ログ A-02 を、GUI 前提で引き継ぐ）。要件分析・ユニット分割の時点で作業量を見直す。
- 1 週間に収まらない場合は、次の順に MVP から外す。
  1. ディスクキャッシュ（intent-backlog の IB-06）
  2. 設定ダイアログ（画面 6。キャッシュ設定とキャッシュ削除だけを持つので、1 と一緒に外れる）
  3. タイムゾーン切替（上部バーの TZ。外す場合はローカル時刻固定にする）
- 上の 3 つを外しても、「古いロググループの過去ログを時刻順に見て、部分一致で絞り込む」という一番の価値（intent-statement）は残る。

## 情報構成

```
メインウィンドウ（1 画面）
+-- 上部バー：プロファイル選択 / リージョン選択 / タイムゾーン切替 / 設定
+-- 左ペイン：ロググループ一覧（名前で絞り込み可）
+-- 右ペイン
    +-- 条件エリア：開始日時 / 終了日時 / [Fetch] / フィルター入力
    +-- ログ一覧：時刻 / ストリーム名 / メッセージ
    +-- ステータス行：状態と件数
設定ダイアログ：ディスクキャッシュの有効・無効、保存場所、キャッシュ削除
終了確認ダイアログ：取得中にウィンドウを閉じるときだけ表示
```

## [Fetch] ボタンが押せる条件

次のすべてを満たすときだけ [Fetch] を押せる。満たさないときは押せない状態で表示し、理由を文字で示す。

- プロファイルとリージョンが選ばれている
- ロググループが 1 つ選ばれている
- 開始日時と終了日時が正しい形式（年月日と時分秒、Q10）で入力されている
- 開始日時が終了日時より前である
- 取得中ではない（Q11）

## 画面 1：メインウィンドウ（起動直後・未選択）

```
+------------------------------------------------------------------------------+
| Profile [dev-sso     v]  Region [ap-northeast-1 v]  TZ [Local v]  [*]        |
+------------------------+-----------------------------------------------------+
| Log groups             | From [yyyy-mm-dd hh:mm:ss]                          |
| Search [............]  | To   [yyyy-mm-dd hh:mm:ss]   [Fetch] (disabled)     |
|  /aws/lambda/app-a     | Filter [......................]                     |
|  /aws/lambda/app-b     +-----------------------------------------------------+
|  /ecs/service-c        |                                                     |
|  /app/batch-d          | Select a log group on the left, set a time          |
|  ...                   | range, then press Fetch.                            |
|                        |                                                     |
+------------------------+-----------------------------------------------------+
| Status: Ready                                                                |
+------------------------------------------------------------------------------+
```

- 空の状態では、ログ一覧の場所に次の操作を案内する文を出す（ロググループ選択 → 時間範囲 → 取得）。
- 日時入力欄は年月日と時分秒（`yyyy-mm-dd hh:mm:ss`）を受け付ける（Q4、Q10）。入力欄の中に形式の例を表示する。
- ロググループ一覧は、選んだプロファイル・リージョンの権限で取得できるものを表示する（scope-document の範囲 2）。
- この時点では条件を満たしていないので [Fetch] は押せない（上の「[Fetch] ボタンが押せる条件」）。
- `[*]` は設定ダイアログを開く。
- **アクセシビリティ**：ウィンドウタイトル「CloudWatch Logs Viewer」。領域は上部バー・左ペイン・右ペイン・ステータス行の 4 つ。Tab の順序は上部バー → ロググループ検索 → ロググループ一覧 → 開始日時 → 終了日時 → Fetch → フィルター → ログ一覧。

## 画面 2：取得中

```
+------------------------------------------------------------------------------+
| Profile [dev-sso     v]  Region [ap-northeast-1 v]   (locked)    [*]         |
+------------------------+-----------------------------------------------------+
| Log groups (locked)    | From [2024-03-01 10:00:00]   (locked)               |
| Search [............]  | To   [2024-03-01 12:00:00]   (locked)               |
|  /aws/lambda/app-a     | [Fetching...] (disabled)                            |
| >/aws/lambda/app-b     +-----------------------------------------------------+
|  /ecs/service-c        |                                                     |
|  /app/batch-d          | Fetching logs ...                                   |
|  ...                   | Profile, region, log group and time range           |
|                        | are locked until fetching finishes.                 |
+------------------------+-----------------------------------------------------+
| Status: Fetching - wide ranges can take several minutes                      |
+------------------------------------------------------------------------------+
```

- MVP には進捗表示と中断がない（scope-document の「受け入れたこと」）。代わりに、取得中であることと、広い時間範囲では数分以上かかりうることを文字で示す。
- 取得中は、プロファイル・リージョン・ロググループ・開始日時・終了日時を変更できない（Q11）。[Fetch] も押せない。
- 取得中に変えられないものは、無効表示にして「(locked)」のように文字で示す。
- スロットリングで待機・再試行している間も「取得中」のままにする（エラーにしない）。
- 取得中にウィンドウを閉じようとしたら、画面 7 の確認を出す（Q12）。
- **アクセシビリティ**：状態は文字（Fetching、locked）と無効表示で示し、色だけに頼らない（Q6）。

## 画面 3：取得完了（ストリームを跨いだ表示）

```
+------------------------------------------------------------------------------+
| Profile [dev-sso     v]  Region [ap-northeast-1 v]  TZ [Local v]  [*]        |
+------------------------+-----------------------------------------------------+
| Log groups             | From [2024-03-01 10:00:00]                          |
| Search [............]  | To   [2024-03-01 12:00:00]   [Fetch]                |
|  /aws/lambda/app-a     | Filter [......................]                     |
| >/aws/lambda/app-b     +-----------------------------------------------------+
|  /ecs/service-c        | Time                 Stream      Message            |
|  /app/batch-d          | 2024-03-01 10:00:01  2024/..a    START ...          |
|  ...                   | 2024-03-01 10:00:02  2024/..f    INFO  ...          |
|                        | 2024-03-01 10:00:05  2024/..a    ERROR ...          |
|                        | ...                                                 |
+------------------------+-----------------------------------------------------+
| Status: 128,431 events from 37 streams (Local time, UTC+09:00)               |
+------------------------------------------------------------------------------+
```

- 列は「時刻 / ストリーム名 / メッセージ」。時刻順に並べる（scope-document の範囲 4）。
- 時刻は選んだタイムゾーンで表示する。ステータス行に、いま表示しているタイムゾーンを明記する（Q5）。
- 長いメッセージは 1 行に収まる分だけ表示し、行を選ぶと全文を読めるようにする（見せ方は要件分析で決める）。
- **アクセシビリティ**：ログ一覧は表として扱い、列見出しを持つ。マウスでの行選択とスクロールに対応する（Q6）。

```

|          aws configure sso), then restart.             |
+--------------------------------------------------------+
| (error)  Credentials for this profile could not        |
|          be loaded. Check the profile settings         |
|          or choose another profile.                    |

| (empty)  No log groups in this region.                 |
|          Choose another region or profile.             |
+--------------------------------------------------------+
| (error)  Could not load log groups: access denied.     |
|          Check IAM permissions or choose another       |
|          profile.                                      |

| (error)  Access denied while fetching logs.            |
|          Check IAM permissions or choose another       |
|          profile.                                      |
+--------------------------------------------------------+
| (error)  Session expired.                              |
|          Run "aws sso login", then Fetch again.        |
+--------------------------------------------------------+
| (error)  Network error or AWS API error.               |
|          Check your connection, then Fetch again.      |

+--------------------------------------------------------+
| (input)  From must be earlier than To.                 |
|          [Fetch] stays disabled until fixed.           |
+--------------------------------------------------------+
```

| 状態 | 表示する場所 | 利用者が次にすること |
|------|--------------|----------------------|
| 時間範囲内にイベントがない | ログ一覧 | 時間範囲を広げる |
| AWS のプロファイルが 1 つもない（初回起動） | ログ一覧と左ペイン | AWS CLI でプロファイルを設定してから再起動する |
| 選んだプロファイルの認証情報を読めない | 左ペイン | プロファイルの設定を確認する、別のプロファイルを選ぶ |
| ロググループが 0 件 | 左ペイン | 別のリージョン・プロファイルを選ぶ |
| ロググループ一覧の取得で権限エラー | 左ペイン | IAM 権限を確認する、別のプロファイルを選ぶ |
| ログ取得で権限エラー | ログ一覧 | IAM 権限を確認する、別のプロファイルを選ぶ |
| SSO セッション切れ | ログ一覧（一覧取得時は左ペイン） | `aws sso login` を実行して、もう一度取得する |
| ネットワーク断・その他の API エラー | ログ一覧（一覧取得時は左ペイン） | 接続を確認して、もう一度取得する |
| 開始日時が終了日時より後・形式が不正 | 日時入力欄の下 | 日時を直す（直すまで [Fetch] は押せない） |

- エラーは何が起きたかと次の行動を文字で示す。生のエラーコードだけを出さない。詳細は短いメッセージとして添える。
- エラーをアイコンや色だけで示さない（Q6）。

## 画面 6：設定ダイアログ

```
+--------------------------------------------+
| Settings                                   |
|                                            |
| [ ] Cache fetched logs on disk             |
|     Location: <user cache folder>          |
|     Logs may contain sensitive data.       |
|     [Clear cache]                          |
|                                            |
|                      [Cancel]  [Save]      |
+--------------------------------------------+
```

- 項目はディスクキャッシュの有効・無効、保存場所の表示、キャッシュ削除だけ（Q13）。タイムゾーンの既定値は置かない（上部バーの TZ 切替で足りる）。
- ディスクキャッシュは既定で無効（scope-document の範囲 6、intent-backlog の IB-06）。有効にするときは、保存場所と「ログに機密情報が含まれうる」ことを表示する。
- キャッシュ削除は、機密情報を含みうるキャッシュを利用者が消せるようにするために残す（Q13）。
- **アクセシビリティ**：ダイアログを開いたら最初の項目に入力位置を移し、閉じたら元の位置に戻す。Escape で閉じる。

## 画面 7：取得中の終了確認

```
+--------------------------------------------------+
| Fetching is in progress.                         |
| If you close the window, the logs fetched so     |
| far will be lost.                                |
|                                                  |
|               [Keep fetching]  [Close]           |
+--------------------------------------------------+
```

- 取得中にウィンドウを閉じようとしたときだけ表示する（Q12）。
- [Keep fetching] で取得を続ける。[Close] で取得途中の結果を捨てて終了する。
- 取得中でなければ、確認なしで閉じる。

## タイムゾーン切替と日時入力

- 上部バーの TZ で、表示と入力のタイムゾーンを切り替える。既定はローカル時刻（Q5）。
- 切り替えても、入力済みの開始・終了日時は**同じ瞬間を保つ**（Q9）。例：ローカル（UTC+9）で `2024-03-01 10:00:00` と入力した後に UTC に切り替えると、入力欄の表示は `2024-03-01 01:00:00` に変わり、取得範囲は変わらない。
- ログ一覧の時刻表示も同じように変わる。再取得は不要。
