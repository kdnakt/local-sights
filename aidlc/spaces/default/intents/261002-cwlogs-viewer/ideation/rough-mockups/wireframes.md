質問票の回答は `rough-mockups-questions.md` の Q1〜Q7 を指す。

## 前提

- デスクトップ GUI アプリ。対応 OS は macOS と Windows（Q1、Q2）。
- 1 画面にすべてを並べる（Q3）。見た目は最小限で、標準的な部品だけを使う（Q7）。
- 画面に載せる機能は MVP の範囲（scope-document、intent-backlog の IB-01〜IB-06）に限る。進捗表示・中断・ファイル書き出し・JSON 整形は MVP 後（intent-backlog の IB-08〜IB-10）なので、ここには描かない。

## 情報構成

```
メインウィンドウ（1 画面）
+-- 上部バー：プロファイル選択 / リージョン選択 / タイムゾーン切替 / 設定
+-- 左ペイン：ロググループ一覧（名前で絞り込み可）
+-- 右ペイン
    +-- 条件エリア：開始日時 / 終了日時 / [取得] ボタン / フィルター入力
    +-- ログ一覧：時刻 / ストリーム名 / メッセージ
    +-- ステータス行：状態と件数
設定ダイアログ：ディスクキャッシュの有効・無効、保存場所、キャッシュ削除
```

## 画面 1：メインウィンドウ（起動直後・未選択）

```
+--------------------------------------------------------------------+
| Profile [dev-sso     v] Region [ap-northeast-1 v] TZ [Local v] [*] |
+------------------------+-------------------------------------------+
| Log groups             | From [03-01 10:00]  To [03-01 12:00]      |
| Search [.............] | [Fetch]                                   |
|  /aws/lambda/app-a     | Filter [....................]             |
|  /aws/lambda/app-b     +-------------------------------------------+
|  /ecs/service-c        |                                           |
|  /app/batch-d          |   Select a log group on the left, set a   |
|  ...                   |   time range, then press Fetch.           |
|                        |                                           |
+------------------------+-------------------------------------------+
| Status: Ready                                                      |
+--------------------------------------------------------------------+
```

- 日時入力欄は絶対日時（年月日と時刻）を受け付ける（Q4）。図では幅の都合で年を省略している。
- 空の状態では、ログ一覧の場所に次の操作を案内する文を出す（ロググループ選択 → 時間範囲 → 取得）。
- ロググループ一覧は、選んだプロファイル・リージョンの権限で取得できるものを表示する（scope-document の範囲 2）。
- `[*]` は設定ダイアログを開く。
- **アクセシビリティ**：ウィンドウタイトル「CloudWatch Logs Viewer」。領域は上部バー・左ペイン・右ペイン・ステータス行の 4 つ。Tab の順序は上部バー → ロググループ検索 → ロググループ一覧 → 開始日時 → 終了日時 → 取得 → フィルター → ログ一覧。

## 画面 2：取得中

```
+--------------------------------------------------------------------+
| Profile [dev-sso     v] Region [ap-northeast-1 v] TZ [Local v] [*] |
+------------------------+-------------------------------------------+
| Log groups             | From [03-01 10:00]  To [03-01 12:00]      |
| Search [.............] | [Fetching...] (disabled)                  |
|  /aws/lambda/app-a     | Filter [....................]             |
| >/aws/lambda/app-b     +-------------------------------------------+
|  /ecs/service-c        |                                           |
|  /app/batch-d          |   Fetching logs ...                       |
|                        |                                           |
+------------------------+-------------------------------------------+
| Status: Fetching (this can take several minutes for wide ranges)   |
+--------------------------------------------------------------------+
```

- MVP には進捗表示と中断がない（scope-document の「受け入れたこと」）。代わりに、取得中であることと、広い時間範囲では数分以上かかりうることを文字で示す。
- 取得中は [取得] ボタンを無効にし、二重実行を防ぐ。
- スロットリングで待機・再試行している間も「取得中」のままにする（エラーにしない）。
- **アクセシビリティ**：状態は文字（Fetching）とボタンの無効化で示し、色だけに頼らない（Q6）。

## 画面 3：取得完了（ストリームを跨いだ表示）

```
+--------------------------------------------------------------------+
| Profile [dev-sso     v] Region [ap-northeast-1 v] TZ [Local v] [*] |
+------------------------+-------------------------------------------+
| Log groups             | From [03-01 10:00]  To [03-01 12:00]      |
| Search [.............] | [Fetch]                                   |
|  /aws/lambda/app-a     | Filter [....................]             |
| >/aws/lambda/app-b     +---------------------+----------+----------+
|  /ecs/service-c        | Time                | Stream   | Message  |
|  /app/batch-d          | 2024-03-01 10:00:01 | 2024/..a | START .. |
|                        | 2024-03-01 10:00:02 | 2024/..f | INFO  .. |
|                        | 2024-03-01 10:00:05 | 2024/..a | ERROR .. |
|                        | ...                 | ...      | ...      |
+------------------------+---------------------+----------+----------+
| Status: 128,431 events from 37 streams (Local time, UTC+09:00)     |
+--------------------------------------------------------------------+
```

- 列は「時刻 / ストリーム名 / メッセージ」。時刻順に並べる（scope-document の範囲 4）。
- 時刻は選んだタイムゾーンで表示する。ステータス行に、いま表示しているタイムゾーンを明記する（Q5）。
- 長いメッセージは 1 行に収まる分だけ表示し、行を選ぶと全文を下部または別ペインで読めるようにする（扱いは要件分析で決める）。
- **アクセシビリティ**：ログ一覧は表として扱い、列見出しを持つ。マウスでの行選択とスクロールに対応する（Q6）。

## 画面 4：フィルター適用中

```
+--------------------------------------------------------------------+
| ... (top bar and left pane: same as screen 3)                      |
+------------------------+-------------------------------------------+
|                        | Filter [timeout............]  [x]         |
|                        +---------------------+----------+----------+
|                        | 2024-03-01 10:14:22 | 2024/..c | ..timeout|
|                        | 2024-03-01 11:02:09 | 2024/..a | ..timeout|
+------------------------+---------------------+----------+----------+
| Status: 2 of 128,431 events match "timeout"                        |
+--------------------------------------------------------------------+
```

- フィルターは文字列の部分一致のみ（Q2 of scope-definition、intent-backlog の IB-05）。取得済みのログに対して絞り込み、AWS への再取得は行わない。
- `[x]` でフィルターを解除する。
- ステータス行に「該当件数 / 全件数」を示す。
- 該当行を色で強調する場合も、該当件数を文字で示し、色だけに頼らない（Q6）。

## 画面 5：該当なし・エラー

```
+-------------------------------------------+
| (empty)  No events in this time range.    |
|          Try a wider range.               |
+-------------------------------------------+
| (error)  Access denied for this profile.  |
|          Check IAM permissions or choose  |
|          another profile.                 |
+-------------------------------------------+
| (error)  Session expired.                 |
|          Run "aws sso login" and Fetch    |
|          again.                           |
+-------------------------------------------+
```

- **該当なし**：時間範囲内にイベントがないことと、次の行動（範囲を広げる）を示す。
- **権限エラー**：何が起きたかと、何をすればよいか（IAM 権限の確認・別プロファイル）を示す。生のエラーコードだけを出さない。
- **SSO セッション切れ**：再ログインの方法を示す。
- エラーはログ一覧の場所に文字で表示し、アイコンや色だけで示さない（Q6）。

## 画面 6：設定ダイアログ

```
+------------------------------------------+
| Settings                                 |
|                                          |
| [ ] Cache fetched logs on disk           |
|     Location: <user cache folder>        |
|     Logs may contain sensitive data.     |
|     [Clear cache]                        |
|                                          |
| Time zone default: (o) Local  ( ) UTC    |
|                                          |
|                    [Cancel]  [Save]      |
+------------------------------------------+
```

- ディスクキャッシュは既定で無効（scope-document の範囲 6、intent-backlog の IB-06）。有効にするときは、保存場所と「ログに機密情報が含まれうる」ことを表示する。
- キャッシュの削除ボタンを用意する。
- **アクセシビリティ**：ダイアログを開いたら最初の項目に入力位置を移し、閉じたら元の位置に戻す。Escape で閉じる。

## 画面状態の一覧

| 状態 | 画面 | 備考 |
|------|------|------|
| 空（未選択） | 画面 1 | 次の操作を案内する |
| 取得中 | 画面 2 | 進捗率・中断はなし（MVP 後） |
| 取得完了 | 画面 3 | 件数とストリーム数を表示 |
| 絞り込み中 | 画面 4 | 該当件数 / 全件数 |
| 該当なし | 画面 5 | 範囲を広げるよう案内 |
| エラー | 画面 5 | 原因と次の行動を示す |
| 大量件数 | 画面 3 | 数十万件でもスクロールできること（「実用的な時間」の数値は要件分析で決める、intent-statement） |
