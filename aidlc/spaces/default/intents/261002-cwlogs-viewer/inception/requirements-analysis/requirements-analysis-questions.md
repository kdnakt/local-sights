X. Other (please specify)

## F1. API 料金の扱いを、料金ページの確認結果をふまえてどう記録しますか？

背景：Q12 の回答を受けて CloudWatch の料金ページ（https://aws.amazon.com/cloudwatch/pricing/ 、日本語版と同内容）を確認した。CloudWatch Logs の課金項目は取り込み・保存・Logs Insights のスキャン量・Live Tail・データ保護などで、API リクエスト料金が載っているのはメトリクス系（PutMetricData、GetMetricData など）だけだった。GetLogEvents・DescribeLogStreams・DescribeLogGroups の呼び出し料金は載っていない。一方、ログを手元に取得する際のデータ転送（インターネットへの送信）料金の扱いは、このページからは確認できなかった。

A. GetLogEvents などの読み取り API の呼び出しは無料と記録する。データ転送料金は未確認の前提とし、最初に実際の AWS で試したあとに請求画面（Cost Explorer）で確認する。キャッシュによる再取得の回避は範囲内のまま
B. 呼び出しは無料、データ転送料金も気にしない（確認もしない）
C. 料金が不明な部分があるため、データ転送料金を公式に確認できるまで要件分析を止める
X. Other (please specify)

[Answer]: A. GetLogEvents などの読み取り API の呼び出しは無料と記録する。データ転送料金は未確認の前提とし、最初に実際の AWS で試したあとに請求画面（Cost Explorer）で確認する。キャッシュによる再取得の回避は範囲内のまま
