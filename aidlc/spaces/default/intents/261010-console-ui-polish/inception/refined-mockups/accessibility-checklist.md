# Accessibility Checklist — 画面を AWS マネジメントコンソールに寄せる

上流：`inception/requirements-analysis/requirements.md`（NFR3、FR3.5、FR4.4）、`mockups.md`、`interaction-spec.md`。目標は WCAG 2.1 AA。Cloudscape の部品は AA を満たす設計のため、ここではアプリ側で確かめる項目に絞る。

## キーボード操作（NFR3）

| # | 項目 | 確かめ方 | 状態 |
|---|---|---|---|
| K1 | 主な流れ（プロファイル → リージョン → ロググループ → 日付・時刻 → [Fetch] → 絞り込み → 一覧）をマウスなしで操作できる | マウスを使わずに一通り操作する | 実装後に確認 |
| K2 | カレンダーをキーボードだけで開き、日を選び、閉じられる | 日付欄で Tab → カレンダーボタン → Enter → 矢印 → Enter → Escape | 実装後に確認 |
| K3 | 上部ナビゲーションのドロップダウンを矢印と Enter で操作できる | Tab で順に移動し、Enter で開く | 実装後に確認 |
| K4 | ロググループの表で ↑↓ と Space で選べる | 表に Tab で入り、↑↓ → Space | 実装後に確認 |
| K5 | ログ一覧で ↑↓ と Enter／Space で展開・閉じられる（MVP U7 の維持） | 表に Tab で入り、↑↓ → Enter | 実装後に確認 |
| K6 | ダイアログは Escape で閉じ、焦点が開いたボタンに戻る | 設定・失敗一覧・確認の各ダイアログ | 実装後に確認 |
| K7 | Tab の順序が mockups.md 画面 1 の記載どおり | Tab を押し続けて順を確認 | 実装後に確認 |
| K8 | 焦点の位置が常に見える（Cloudscape の焦点リング） | 各部品で確認 | 実装後に確認 |

## 読み上げと意味づけ

| # | 項目 | 確かめ方 | 状態 |
|---|---|---|---|
| S1 | 日付欄・時刻欄に見える label と aria-label がある | VoiceOver で欄に移動して読み上げを聞く | 実装後に確認 |
| S2 | 欄の直下の理由（errorText）が欄に結びつき、変更時に読み上げられる | 不正な値を打って読み上げを聞く | 実装後に確認 |
| S3 | 取得全体の失敗の Alert が `role="alert"` で読み上げられる | 失敗させて確認 | 実装後に確認 |
| S4 | ステータス行が `aria-live="polite"` で件数・状態の変化を伝える | 取得して確認 | 実装後に確認 |
| S5 | ロググループの表・ログ一覧の表に見出し行と選択の読み上げがある | VoiceOver で確認 | 実装後に確認 |
| S6 | 見出しの階層が h1（アプリ名）→ h2（Log groups、ロググループ名）→ h3（ダイアログ）で飛びがない | 見出し一覧で確認 | 実装後に確認 |

## 入力の誤りの防止と回復

| # | 項目 | 確かめ方 | 状態 |
|---|---|---|---|
| E1 | 欄の直下の理由が「何を直すか」を具体的に言う（形式の例を含む） | interaction-spec.md §9 の文言 | 文言を確定済み |
| E2 | 不備がある間は [Fetch] が無効で、理由が消えると有効になる | 入力を直して確認 | 実装後に確認 |
| E3 | 時刻の補完は欄の表示に反映され、黙って別の値で取得しない | `10:00` と打って焦点を外し、`10:00:00` になるのを確認 | 実装後に確認 |
| E4 | 取得中に閉じようとすると確認が出る（MVP の維持） | 取得中に Cmd+Q | 実装後に確認 |
