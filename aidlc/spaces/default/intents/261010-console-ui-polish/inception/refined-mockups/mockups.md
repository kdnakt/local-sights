## 画面 1：メインウィンドウ（起動直後・未選択）

```
+------------------------------------------------------------------------------------+
| # local-sights                 Profile: default v | ap-northeast-1 v | Local v | (*) |  <TopNavigation>
+------------------------------------------------------------------------------------+
| +-- Log groups ------------------+ +-- Select a log group ------------- [Fetch] --+ |
| | [q Find log groups        ]    | |                                              | |  <Container><Header>
| | +----------------------------+ | | [q Filter events        ] Start [yyyy/mm/dd|v] [hh:mm:ss] |
| | | ( ) /aws/lambda/app-a      | | |                           End   [yyyy/mm/dd|v] [hh:mm:ss] |
| | | ( ) /aws/lambda/app-b      | | |                                              | |
| | | ( ) /ecs/service-c         | | | +------------------------------------------+ | |
| | | ( ) CloudTrail             | | | | Timestamp (Local) | Stream | Message     | | |  <Table>
| | | ( ) MyLogGroup             | | | +------------------------------------------+ | |
| | |                            | | | |  No events                               | | |
| | +----------------------------+ | | |  Select a log group, set a time range,   | | |
| | [Reload]                       | | |  then choose Fetch.                      | | |
| +--------------------------------+ | +------------------------------------------+ | |
|                                    +----------------------------------------------+ |
| Ready                                                                              |  <Box> status line
+------------------------------------------------------------------------------------+
```

- 上部ナビゲーション（Q1、FR4.1）：左にアプリ名、右にプロファイル（ドロップダウン）、リージョン（ドロップダウン）、タイムゾーン（ドロップダウン：Local / UTC）、歯車アイコンの設定ボタン。今のラジオボタン（タイムゾーン）とセレクト（プロファイル・リージョン）は、すべて上部ナビゲーションのドロップダウンに置き換える。接続を変えられないとき（取得中・確認待ち）はドロップダウンを無効にする（MVP の振る舞いの維持、FR4.4）。
- 左ペイン（Q6、FR4.2）：見出し「Log groups」の囲み。検索欄（名前の部分一致、既存の絞り込み）、1 行選択の表（ラジオ付き、列はロググループ名のみ）、[Reload]。表の読み込み中・空・一部失敗の状態は画面 5 を参照。
- 右ペイン（Q2、FR4.2）：囲みの見出しは選択中のロググループ名（未選択時は「Select a log group」）、右端に主ボタン [Fetch]（押せないときは無効）。その下の 1 行に、左から絞り込み欄（ログのメッセージの部分一致。幅は残り全部）、右に開始と終了の日付欄（カレンダー付き、`yyyy/mm/dd`）＋時刻欄（`hh:mm:ss`）を 2 段で置く。ラベルには選択中のタイムゾーンを添える（例：Start (Local)）。
- ログ一覧（Q3、FR2.2、FR4.3）：列は Timestamp / Stream / Message の順で変えない。時刻列の見出しにタイムゾーンを添える。空のときはコンソールの表と同じ「空の状態」の文言を表の中に出す。
- ステータス行：表の下に 1 行。内容は今のまま（件数、取得中、失敗した件数のボタン、キャッシュの通知）。
- 最小ウィンドウ 1024×640（NFR7）で、左ペイン 18rem・右ペイン残り。条件行は 1024px で絞り込み欄と日付・時刻が 1 行に収まらなければ、日付・時刻を絞り込み欄の下に折り返す。
- **アクセシビリティ**：Tab の順序は上部ナビゲーション（プロファイル → リージョン → タイムゾーン → 設定）→ ロググループ検索 → ロググループ表 → [Reload] → [Fetch] → 絞り込み欄 → 開始の日付 → 開始の時刻 → 終了の日付 → 終了の時刻 → ログ一覧。見出しは h1（アプリ名、上部ナビゲーション）、h2（Log groups、ロググループ名）。

## 画面 2：日付・時刻の入力とカレンダー（FR1、FR2）

```
  Start (Local)                        End (Local)
  [2024/03/01       |v] [10:00:00]     [2024/03/01       |v] [12:00:00]
                     |
                     v  (DatePicker のカレンダー)
   +-------------------------------+
   |  <   March 2024          >    |
   |  Su Mo Tu We Th Fr Sa         |
   |                  1  2         |
   |   3  4  5  6  7  8  9         |
   |  ...                          |
   +-------------------------------+
```

- 日付欄（Q1 の要件 FR1.1、FR1.2）：Cloudscape の DatePicker。表示と入力は `yyyy/mm/dd`。カレンダーボタンでカレンダーが開き、日付を選ぶと欄に入る。キーボードで `2024/03/01` と直接打てる。カレンダーは矢印キーで日を移動、Enter で選択、Escape で閉じる（NFR3）。
- 時刻欄（FR1.3、Q4、Q5）：Cloudscape の TimeInput（24 時間、`hh:mm:ss`）。焦点が外れたときに補完する：`hh:mm` → `hh:mm:00`（開始）／`hh:mm:59`（終了）、空 → `00:00:00`（開始）／`23:59:59`（終了）。欄の表示も補完後の値に書き換える。
- 日付が空のときは補完しない（日付は必須）。日付欄が空のまま [Fetch] を見ると、日付欄の直下に理由が出る（画面 5）。
- タイムゾーンを切り替えると（上部ナビゲーションのドロップダウン）、両方の欄の値が同じ瞬間を保ったまま書き換わる（FR1.5）。
- カレンダーでは、終了より後の開始日も選べる。選んだ結果の順序の誤りは、終了の日付欄の直下に理由として出す（FR3.1、要件レビュー R-04 の方針）。
- 存在しない日付（`2024/02/30`）やハイフン区切り（`2024-03-01`）を打った場合は、日付欄の直下に形式の誤りを出す（FR2.4）。

## 画面 3：取得中

```
+------------------------------------------------------------------------------------+
| # local-sights                 Profile: default v | ap-northeast-1 v | Local v | (*) |  (all disabled)
+------------------------------------------------------------------------------------+
| +-- Log groups (disabled) -------+ +-- /aws/lambda/app-b ------------ [Fetch] -----+ |
| | ...                            | | [q Filter events   ] Start [2024/03/01] [10:00:00] (disabled) |
| |                                | |                      End   [2024/03/01] [12:00:00] (disabled) |
| |                                | | +------------------------------------------+ | |
| |                                | | | Timestamp (Local)     | Stream | Message | | |
| |                                | | | 2024/03/01 10:00:01.123 | ..a  | START.. | | |
| |                                | | | ...                                      | | |
| +--------------------------------+ | +------------------------------------------+ | |
|                                    +----------------------------------------------+ |
| (o) Fetching 12 / 37 streams, 48,210 events                                       |  <StatusIndicator type=loading>

```

- 取得中は、上部ナビゲーションの接続のドロップダウン、ロググループの表、日付・時刻、[Fetch] を無効にする（FR1.8、FR4.4）。絞り込み欄は使える（MVP の振る舞い）。
- ステータス行は Cloudscape の StatusIndicator（loading）で「取得中」を示し、件数を文字で出す（project.md の最低限の状態表示）。
- 届いたぶんの行はそのまま表に増えていく（MVP の振る舞い）。

## 画面 4：取得完了・行の展開・絞り込み

```
| +-- /aws/lambda/app-b -------------------------------------------- [Fetch] -----+
| | [q timeout            ] Start [2024/03/01] [10:00:00]  End [2024/03/01] [12:00:00] |
| | +----------------------------------------------------------------------------+ |
| | | Timestamp (Local)        | Stream        | Message                         | |
| | +----------------------------------------------------------------------------+ |
| | | 2024/03/01 10:14:22.004  | 2024/03/01/[$LATEST]a1 | ...connection timeout.. | |
| | |   {                                                                        | |  (expanded row: full text,
| | |     "level": "error",                                                      | |   monospace, wraps, up to 20 lines,
| | |     "msg": "connection timeout after 30s"                                  | |   scrolls inside beyond that)
| | |   }                                                                        | |
| | | 2024/03/01 11:02:09.517  | 2024/03/01/[$LATEST]c3 | ...read timeout...      | |
| | +----------------------------------------------------------------------------+ |
| 2 of 128,431 events match                                                        |
```

- 行を押すと直下に全文を展開し、もう一度押すと閉じる。複数行を同時に展開できる。全文は選択してコピーできる。↑↓ で行を選び、Enter か Space で展開・閉じる（FR4.4 の維持）。
- 時刻列は `yyyy/mm/dd hh:mm:ss.SSS`（FR2.2）。
- 絞り込み欄の文字で部分一致の絞り込みをし、ステータス行に「該当 / 全件」を出す（MVP の振る舞い）。
- 表の実装は Q3 のとおり：まず Cloudscape の Table で作り、100 万行のダミーで NFR2（絞り込み 100 秒以内、スクロール・展開に 1 秒以内に反応）を測る。満たせなければ、今の自前の仮想スクロールにデザイントークン（罫線・配色・余白・文字・見出し）を当てる。どちらにしても見た目は上の図と同じにする。

## 画面 5：入力不備・エラー（FR3）

### 5a 入力不備（欄の直下）

```
| +-- Select a log group ------------------------------------------- [Fetch] -----+   (Fetch disabled)
| |   ! Choose a log group.                                                      |   <FormField errorText>
| | [q Filter events      ] Start [2024/13/01    |v] [10:00:00]                   |
| |                              ! Enter the date as yyyy/mm/dd.                  |   <FormField errorText>
| |                         End   [2024/03/01    |v] [        ]                   |
```

- 「取得できない理由：」の箇条書きは廃止（FR3.1）。各理由は該当する欄の直下に、Cloudscape の FormField の errorText（赤い文字＋アイコン）で出す。
- 紐づけ：ロググループ未選択・名前が長すぎる → 見出し行のロググループ名の直下。開始の形式・存在しないローカル時刻 → 開始の日付欄（形式）または時刻欄（存在しない時刻）の直下。終了も同様。開始が終了より後 → 終了の日付欄の直下。
- 理由が出ている間、[Fetch] は無効。理由は文字で出し、色だけに頼らない（FR3.5）。

### 5b 取得全体の失敗（表の上のアラート）

```
| | [q Filter events      ] Start [...] [...]  End [...] [...]                    |
| | +----------------------------------------------------------------------------+ |
| | | (x) Access was denied.                                                 [x] | |  <Alert type=error dismissible>
| | |     Check the IAM permissions of the profile, or choose another profile.   | |
| | |     Detail: AccessDeniedException: User ... is not authorized ...          | |
| | +----------------------------------------------------------------------------+ |
| | +-- Timestamp (Local) | Stream | Message ---------------------------------+   |
```

- 取得全体の失敗は、表の直上に Cloudscape の Alert（type=error、閉じるボタン付き）。1 行目に何が起きたか（見出し）、2 行目に次の行動、3 行目に安全な詳細（あれば）（FR3.2）。取得できたぶんの行は下の表に残る（MVP の振る舞い）。
- 閉じると消え、ステータス行の「何が起きたか」の短い文は残る（FR3.3）。

### 5c ロググループ一覧の失敗（左ペイン）

```
| +-- Log groups ------------------+
| | [q Find log groups        ]    |
| | +----------------------------+ |
| | |  (x) Could not load log    | |   (table empty state with the error in words)
| | |      groups. Check the IAM | |
| | |      permissions ...       | |
| | +----------------------------+ |
| | [Reload]                       |
```

- 左の表の「空の状態」に、何が起きたか・次の行動・詳細を文字で出す（FR3.3、MVP の振る舞い）。一部だけ取れたときは、表の上に Alert（type=warning）で「一覧は一部です」と出す。

### 5d ストリームごとの失敗一覧（ダイアログ）

```
   +-- Failed streams ------------------------------------------[x]-+
   | Stream                     | What happened / what to do          |   <Modal> + <Table>
   | 2024/03/01/[$LATEST]a1     | Throttled. Fetch again later.       |
   | 2024/03/01/[$LATEST]c3     | Could not connect to AWS. ...       |
   |                                                      [Close]     |
   +------------------------------------------------------------------+
```

- ステータス行の「N streams failed」ボタンで開く。中身と置き場所は今のまま、部品を Modal と Table に置き換える（FR3.3）。Escape と [Close] で閉じ、焦点はボタンに戻る。

## 画面 6：設定ダイアログ・確認ダイアログ・終了確認

```
   +-- Settings -------------------------------------------------[x]-+
   | [v] Keep fetched logs in the disk cache                          |   <Modal> <Checkbox>
   |     Cache folder: ~/Library/Caches/local-sights                  |
   |     Logs may contain confidential information.                   |
   |                                    [Clear cache] [Cancel] [Save] |   <Button>
   +------------------------------------------------------------------+
```

- 歯車アイコンのボタン（上部ナビゲーション右端、Q1）で開く。中身は今のまま（キャッシュの有効・無効、保存場所、注意、[Clear cache]、[Cancel]、[Save]）。
- 接続変更の確認（表示中のログがあるとき）と、取得中の終了確認も同じ Modal。ボタンの並びは Cloudscape の慣例どおり右寄せで、主ボタンを右端にする。

## 画面 7：ダークモード（FR4.5）

- OS がダークのときは、Cloudscape のダークモードを全体に適用する。上部ナビゲーションは明暗とも黒。
- 明暗どちらでも、エラーの文字・アイコン・囲みの対比は Cloudscape のトークンに任せる（独自の色は使わない）。
