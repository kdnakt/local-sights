## 1. 意図の分析

- **何を達成したいか**：既存の local-sights の画面を、AWS マネジメントコンソールのログイベント画面になるべく近い見た目にする。名前が挙がったのはエラー表示・日付のスラッシュ表記・カレンダー入力・日付と時刻の分離の 4 点で、それに加えて全体の見た目の調子と画面の構成も寄せる（[desc]、意図整理 Q1）。
- **何に困っているか**：ハイフン区切りの日付入力が面倒でコンソールと違って戸惑う、日時の手入力自体が面倒、「取得できない理由」の箇条書きが読みにくい、日付と時刻が 1 つの欄で直しにくい（意図整理 Q2）。
- **誰のためか**：開発者本人。あわせて OSS の利用者（意図整理 Q5）。
- **なぜ今か**：OSS として公開する前に、見られる見た目にしておきたい（意図整理 Q4）。
- **種類と規模**：既存アプリ（Rust のコア＋React/Tauri の画面）の改修。画面側が中心で、コア側は日付の解析・表記の変更に限る。複雑さは Standard。

## 2. 機能要件

### FR1. 日付と時刻の入力（分離とカレンダー）

- **FR1.1** 開始・終了それぞれに、日付の欄と時刻の欄を別々に置く。日付の欄にはカレンダーが付き、カレンダーから選んだ日付は `yyyy/mm/dd` で欄に入る（意図整理 Q7、RA Q1）。
- **FR1.2** 日付の欄はキーボードでも `yyyy/mm/dd` の形で直接打てる。カレンダーもキーボードだけで開いて日付を選べる（MVP NFR13 の維持）。
- **FR1.3** 時刻の欄は `hh:mm:ss` を基本とし、`hh:mm` だけ打った場合は秒を補って受け付ける。開始は `:00`、終了は `:59` を補う（RA Q2）。
- **FR1.4** 日付と時刻の両方が揃って有効な入力になる。片方だけ、または不正な値のときは [Fetch] は押せず、理由がその欄の直下に出る（FR3.1）。
- **FR1.5** タイムゾーンを切り替えても、入力済みの開始・終了は同じ瞬間を指したまま表示だけが変わる（MVP FR3.3 の維持）。表記は `yyyy/mm/dd` と `hh:mm:ss`。
- **FR1.6** 終了はその秒の終わりまで（ミリ秒を含めて）範囲に含む（MVP FR3.5 の維持）。
- **FR1.7** 夏時間の切り替えで存在しない日時は不正として扱い、2 回現れる日時は早い方とする（MVP FR3.6 の維持）。
- **FR1.8** 取得中は日付・時刻の欄とカレンダーを操作できない（MVP FR4.8 の維持）。

受け入れ基準：
- Given 開始の日付欄が空 When カレンダーを開いて 2024 年 3 月 1 日を選ぶ Then 欄に `2024/03/01` が入る
- Given 開始の日付欄 When `2024/03/01` とキーボードで打つ Then カレンダーを使わずに同じ値として受け付けられる
- Given 開始の時刻欄に `10:00` と打つ When 焦点を外す Then `10:00:00` として扱われる。終了の時刻欄に `10:00` なら `10:00:59` として扱われる
- Given 開始の日付が `2024/03/01`、時刻が空 When [Fetch] を見る Then 押せず、開始の時刻欄の直下に理由が出る
- Given ローカル（UTC+9）で `2024/03/01` `10:00:00` と入力した後 When UTC に切り替える Then 欄は `2024/03/01` `01:00:00` になり、取得範囲は変わらない
- Given 終了が `2024/03/01` `10:00:00` When 時刻 `10:00:00.999` のイベントがある Then 取得・表示される
- Given 日付欄に `2024/13/01` と打つ When [Fetch] を見る Then 押せず、日付欄の直下に形式の誤りが出る

### FR2. 日付と時刻の表記

- **FR2.1** 入力欄の日付は `yyyy/mm/dd`、時刻は `hh:mm:ss` で表示・入力する（RA Q1、RA Q2）。
- **FR2.2** ログ一覧の時刻列は `yyyy/mm/dd hh:mm:ss.SSS`（ミリ秒付き）で表示する（RA Q1）。列の並び（時刻・ストリーム名・メッセージ）は変えない（意図整理 Q6）。
- **FR2.3** 入力の形式を説明する文言（欄の説明、エラーの理由）も `yyyy/mm/dd` と `hh:mm:ss` で書く。`yyyy-mm-dd hh:mm:ss` の表記は画面から消す。
- **FR2.4** 日付欄にハイフン区切り（`yyyy-mm-dd`）を打った場合は、形式の誤りとして扱う（コンソールの日付欄と同じ。前提 AS2）。

受け入れ基準：
- Given 時刻 `2024-03-01T01:00:00.123Z` のイベント When ローカル（UTC+9）で一覧に出す Then `2024/03/01 10:00:00.123` と表示される
- Given 日付欄に `2024-03-01` と打つ When [Fetch] を見る Then 押せず、欄の直下に `yyyy/mm/dd` の形で入力するよう理由が出る

### FR3. エラーと入力不備の見せ方

- **FR3.1** 入力の不備は、該当する入力欄の直下に、コンソールの入力欄のエラー文言と同じ見た目（赤い文字＋文言）で出す。「取得できない理由：」の箇条書きは廃止する（RA Q4、意図整理 Q2）。どの欄にも属さない不備は次の欄に紐づける：ロググループ未選択・名前が長すぎる → 選択中ロググループの表示の直下、開始が終了より後 → 終了の日付欄の直下。
- **FR3.2** 取得全体の失敗は、ログ一覧の上にコンソール風の囲み（エラーの種類のアラート）で出す。「何が起きたか」「次の行動」「詳細（あれば）」の 3 行構成（MVP FR8.1）は維持し、囲みは閉じられる（RA Q4）。
- **FR3.3** ストリームごとの失敗一覧ダイアログとステータス行は、置き場所と内容を変えず、部品だけコンソール風に置き換える（RA Q4）。
- **FR3.4** エラーの中身（種類の判定、文言の組み立て、安全な詳細の扱い）は変えない。見せ方だけを変える（意図整理 Q6）。
- **FR3.5** エラーを色やアイコンだけで示さず、文字でも示す（MVP FR8.2 の維持）。エラー表示に秘密の認証情報とアクセスキー ID を出さない（MVP FR8.3 の維持）。

受け入れ基準：
- Given ロググループを選んでいない When 条件エリアを見る Then 選択中ロググループの表示の直下に「ロググループを選んでください」に相当する理由が出て、[Fetch] は押せない
- Given 開始 `2024/03/02 00:00:00`、終了 `2024/03/01 00:00:00` When 入力する Then 終了の日付欄の直下に順序の誤りが出て、[Fetch] は押せない
- Given 権限がなく取得全体が失敗する When [Fetch] を押す Then ログ一覧の上にエラーの囲みが出て、何が起きたか・次の行動・詳細の 3 行が読め、閉じると消える
- Given 取得全体が失敗した When 画面を見る Then 失敗は文字で読め、色だけで示されていない

### FR4. コンソール風の見た目と画面の構成

- **FR4.1** 画面に見える部品（ボタン・選択・入力欄・ラジオ・表・ダイアログ・見出し・囲み・通知）は、すべて Cloudscape Design System の部品に置き換える（RA Q3）。
- **FR4.2** 左にロググループ一覧、右に条件エリアとログ一覧の 2 ペインは保つ。左の一覧も右の条件エリア・ログ一覧も、全体的にコンソールのログイベント画面に似せる：見出し、囲み（コンテナ）、ボタンの並び、絞り込み欄と期間指定の配置（RA Q5）。具体的な配置は画面案（Refined Mockups）で 1 回で決める。
- **FR4.3** ログ一覧の列と並び（時刻・ストリーム名・メッセージ）は変えない（意図整理 Q6）。
- **FR4.4** 既存の振る舞いは維持する：行の展開・閉じる、キーボードでの行選択、取得中の操作ロック、接続変更と終了の確認ダイアログ、設定ダイアログ、ロググループの絞り込み、ログの絞り込み（意図整理 Q6）。
- **FR4.5** ダークモードは OS の設定に合わせる。明暗どちらでも Cloudscape のテーマで描く（RA Q6）。
- **FR4.6** 画面の文言は引き続き英語と日本語を用意し、Cloudscape の部品が持つ文言（カレンダーの月名・曜日、閉じるボタンの読み上げ名など）も OS の言語に合わせる（MVP NFR12 の維持）。

受け入れ基準：
- Given アプリを起動する When 画面を見る Then 見える部品がすべて Cloudscape の部品で描かれている（開発者が部品一覧と照合する）
- Given OS をダークモードにする When アプリを見る Then 再起動なしで Cloudscape のダーク表示になる
- Given OS の言語が日本語 When カレンダーを開く Then 月名と曜日が日本語で出る
- Given 行を押す When 展開する Then 展開・閉じる・複数展開・コピーが今までどおり動く
