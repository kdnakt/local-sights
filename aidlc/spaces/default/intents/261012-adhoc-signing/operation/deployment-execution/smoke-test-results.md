# Smoke Test Results — リリースの .app をアドホック署名する

## 状態

**未実施（開発者が `v0.1.1` の公開後に行う）**。スモークテストは公開された `.dmg` を macOS 15 の Mac で開く操作であり、この作業環境（Linux）では実行できない。CI でも Gatekeeper の挙動は確かめられない（要件分析 Q3 の回答：実際のリリース後に確かめる）。

## 手順と期待値（開発者の macOS 15 の Mac）

| # | 操作 | 期待 | 結果 |
|---|---|---|---|
| S1 | Release ワークフロー（タグ `v0.1.1`）の「the .app carries a valid ad-hoc signature」ステップのログを見る | `codesign --verify` が成功し、`codesign -dvv` の出力に `Signature=adhoc` がある。Release が公開されている | 未 |
| S2 | ブラウザで `Local-Sights_0.1.1_aarch64.dmg` をダウンロードし、`Local Sights.app` を `/Applications` にドラッグする | ダウンロードした `.dmg` に隔離属性が付く（ブラウザ経由） | 未 |

| S4 | システム設定 → プライバシーとセキュリティ → セキュリティ の「"Local Sights" はブロックされました」で **このまま開く** を押し、パスワードまたは Touch ID で確認する | ボタンがあり、確認できる | 未 |

## 失敗時

- S1 が失敗：Release は作られていない。`rollback-runbook.md` の事象 1。
- S3 で「壊れている」が出た：公開済みだが配布しない。`rollback-runbook.md` の事象 2。`codesign -dvv` を取り出した `.app` に実行し、署名の有無を記録する。
- S3〜S5 の文言が手順書と違う：起動できていれば配布は続行し、`docs/install.md` の文言を次のパッチで直す。
