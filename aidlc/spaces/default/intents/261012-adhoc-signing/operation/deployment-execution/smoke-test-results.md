# Smoke Test Results — リリースの .app をアドホック署名する

## 状態

**成功（2026-10-12、会社の端末で確認）**。`v0.1.1`（Release run 38248098159、コミット `621f0f0`）の `.dmg` を会社の Mac に入れて初回起動したところ、「"Local Sights" は開いていません。Apple は、"Local Sights" に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。」の警告（**ゴミ箱に入れる** / **完了**）が出た。`v0.1.0` の「壊れているため開けません」ではない。システム設定の **このまま開く** で起動できた（ターミナルは使っていない）。会社の端末管理（MDM）は「このまま開く」を禁止していなかった。

実際の警告の見出しは手順書の想定（"could not verify"）と同じ種類だが、日本語の見出しは「開いていません」だった。`docs/install.md` は英語の文言で書いており、本文の意味は一致している。

## 失敗時

- S1 が失敗：Release は作られていない。`rollback-runbook.md` の事象 1。
- S3 で「壊れている」が出た：公開済みだが配布しない。`rollback-runbook.md` の事象 2。`codesign -dvv` を取り出した `.app` に実行し、署名の有無を記録する。
- S3〜S5 の文言が手順書と違う：起動できていれば配布は続行し、`docs/install.md` の文言を次のパッチで直す。
