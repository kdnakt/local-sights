# Build Instructions — 261012-parallel-fetch

## 前提

| もの | 版 | 備考 |
|------|----|------|
| Rust | stable（確認時 1.97.0） | CI は `dtolnay/rust-toolchain`（stable） |
| Node.js / npm | 22 系（確認時 v22.22.0 / 10.9.4） | CI は `node-version: 22` |
| cargo-llvm-cov | 0.9.1 | カバレッジの測定（CI と同じ版） |
| cargo-deny | CI と同じもの | 依存関係の検査 |
| Tauri のビルドに要る OS の部品 | macOS は Xcode Command Line Tools、Linux は webkit2gtk など | GUI を動かすのは開発者の手元の macOS |

## 依存関係を入れる

```sh
npm ci                 # 画面側（package-lock.json どおり）
cargo fetch            # Rust 側（Cargo.lock どおり）
```

この作業で足した依存は `futures-util`（`default-features = false, features = ["std"]`）だけ。画面側の依存は増えていない。

## 環境の準備

- 自動テストとビルドに環境変数・設定ファイル・手元のサービスは要らない。実際の AWS には接続しない（project.md の Forbidden）。
- 手元の確認（実際の AWS）だけは、開発者本人の `~/.aws/config` のプロファイルと認証情報を使う。手順は `performance-test-instructions.md` の「手元の確認」を見る。認証情報をリポジトリ・ログ・画面に書かない。

## ビルド

```sh
cargo build --workspace            # ライブラリ（local-sights-core）とアプリ（local-sights）
npx tsc --noEmit                   # 画面の型検査
npx vite build                     # 画面のバンドル
npm run check:version              # Cargo.toml・package.json・tauri.conf.json の版がそろっていること
```

アプリを手元で起動するとき（macOS）：

```sh
npm run tauri dev
```

## ビルドの確かめ方

| 確かめること | コマンド | 期待 |
|--------------|----------|------|
| 書式 | `cargo fmt --all --check`、`npx prettier --check .` | 終了コード 0 |
| リンタ | `cargo clippy --workspace --all-targets`、`npx eslint .` | 終了コード 0（clippy の警告はエラー扱いにしない：team.md） |
| アプリのビルド | `cargo build -p local-sights` | 終了コード 0 |
| 画面のビルド | `npx vite build` | 終了コード 0 |
| 確認用プログラム | `cargo test -p local-sights-core --example fetch_check` | 終了コード 0 |

## よくあるつまずき

- **Tauri の権限の自動生成ファイルの差分**：`src-tauri/build.rs` のコマンドの一覧を変えると `src-tauri/permissions/autogenerated/` が作り直される。この作業では `cancel_fetch.toml` が増えた。生成されたファイルもコミットする。
- **`check:version` の失敗**：版の欄のどれかだけを変えたとき。5 つのファイルの版をそろえる（team.md の Deployment）。
- **Linux で `cargo build -p local-sights` が webkit2gtk を見つけられない**：`libwebkit2gtk-4.1-dev` などの OS の部品を入れる。CI のアプリのジョブは Ubuntu と macOS の両方で動き、Ubuntu では必要な部品を入れている（`.github/workflows/ci.yml`）。
- **`cargo llvm-cov` が無い**：`cargo install cargo-llvm-cov --version 0.9.1 --locked`。
