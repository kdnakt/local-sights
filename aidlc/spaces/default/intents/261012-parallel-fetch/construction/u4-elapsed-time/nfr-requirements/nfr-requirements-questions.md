# NFR Requirements 質問票 — U4 かかった時間（u4-elapsed-time）

上流：`construction/u4-elapsed-time/functional-design/`（rules.md BR4.1〜BR4.10、functional-spec.md、レビュー 1 回目の R-01〜R-06）、`inception/requirements-analysis/requirements.md`（FR4.1〜FR4.6、NFR6〜NFR9）、`inception/contract-design/contract-summary.md`（C4、C5）、`codekb/local-sights/technology-stack.md`。

U4 は作業単位の種類が service で、AppSession に経過の記録を足し、SessionView に `elapsed` を足し、画面の状態行に経過を出す。AWS の呼び出し・保存先・依存は変えない。機能設計のレビューの軽微な指摘は、次のように扱う。

## 前提として決めたこと（質問にしない技術的な決め）

- **R-01（合わせ直しの契機）**：画面が時計を合わせ直すのは、`session-changed` で新しい SessionView が届いたときだけとする。`fetch-progress`・`filter-progress` で画面の中で組み立て直した session では合わせ直さない。SessionView は取得の始まり・ストリームの計画・ストリームの終わり・取得の終わりなどで届き、一覧の進み・ページ・保存の知らせは `fetch-progress` で届く（今の送り方）。
- **R-02（読み上げから外す方法）**：取得中は経過の部分に `aria-hidden="true"` を付け、終わったら外す。テストはその属性の有無で確かめる。
- **R-03（描き直しの範囲）**：1 秒ごとの描き直しは、経過だけを描く小さな部品の中に閉じ込める。状態行の残りやログの表は毎秒描き直さない。
- **R-04（時計の差し替え）**：AppSession の時計は、組み立てるときに渡せる小さな型にする（本番は戻らない時計、テストは決まった時刻を返すもの）。今の AppSession と同じく複製でき、別のタスクと共有できる形にする。
- **R-05（AC2.1.3 との関係）**：接続を変えて前の結果が消えるときに経過も消す（BR4.4）のは、機能設計の Q2 で利用者が選んだ扱いとして、この段の対応表と要件に書く。SessionView の `elapsed` が空になるのは「一度も取得していない」「閉じて止めた」「接続の変更で前の結果が消えた」の 3 つとする。
- **R-06**：下の Q1 で決める。

## Q1. 取得中に、経過の数字が 1 秒戻って見えることを許しますか？

背景：取得中、画面は自分の時計で経過を進め、ライブラリから新しい値が届くたびに合わせ直します（ADR-005）。届くまでのわずかな遅れのため、合わせ直した瞬間に表示が 1 秒戻ることがあります（例：00:09 → 00:08）。終わったときの最終の値は、ライブラリの値をそのまま出します。

A. 取得中は数字を戻さない（推奨）：合わせ直しの値が今の表示より小さいときは今の表示を保ち、次の 1 秒で追いつかせる。終わったときだけ最終の値に置き換える（ここで 1 秒戻ることはありうる）
B. 戻ることを許す：受け取った値にそのまま合わせる。仕組みは少し簡単になるが、取得中に数字が減って見えることがある
X. Other (please specify)

## Consolidated Summary Confirmation

- AWS の呼び出し・権限・保存先・依存は足さない。経過は時刻と長さだけで、秘密の情報を含まない
- 経過のために画面へ送る回数は増やさない（秒ごとには送らない）。1 秒ごとの描き直しは経過だけを描く小さな部品に閉じ込め、ログの表は毎秒描き直さない
- 取得中の表示は 1 秒ごとに進み（再試行の待ちの間も）、ライブラリの値とのずれは 1 秒以内に収める。取得中は数字を戻さず、終わったときだけ最終の値に置き換える（Q1）
- 合わせ直しは `session-changed` で新しい SessionView が届いたときだけ
- 読み上げ：取得中は経過の部分に `aria-hidden="true"` を付け、終わったら外す
- 時計：ライブラリも画面も戻らない時計で数え、テストで差し替えられる形にする（ライブラリは組み立てるときに渡せる小さな型）
- 接続の変更で経過が消えるのは機能設計の Q2 で選んだ扱いとして対応表に書く。`elapsed` が空になるのは「一度も取得していない」「閉じて止めた」「接続の変更で前の結果が消えた」の 3 つ
