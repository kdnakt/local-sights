# Intent Statement — ロググループ全体の取得の高速化

## Problem Statement

ロググループ全体を取得するとき、いまはストリームを 1 つずつ順に取得しているため、ストリームの多いロググループほど待ち時間が延びる。 [desc] [memory:M2]

とくに困っているのは、ストリームが数十〜数百本あるロググループで、短い時間範囲を取得する場面である。 [Q1]

この作業は、その待ち時間を短くすることをねらう。速くする手段は、これまでと同じ読み取りの 3 つの呼び出し（DescribeLogGroups / DescribeLogStreams / GetLogEvents）だけに限る。 [desc] [memory:M1]

あわせて、取得の進み具合を画面に示し、取得を途中で止められるようにする。いまは取得を途中で止める手段がない。 [Q8]
