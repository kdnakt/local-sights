# Accessibility Checklist — ロググループ全体の取得の高速化

対象は今回変える 3 か所（ボタン、経過、中断の注意）。基準は WCAG 2.1 AA。VoiceOver を超える対応は、前回の要件で対象外としている（261002 の requirements の対象外）ため、今の水準を保つことを目標にする。

| 項目 | 確かめること | 対象 | 要件・ストーリー |
|------|--------------|------|------------------|
| キーボード操作 | ［中断］が［取得］と同じ位置・同じタブ順にあり、Enter / Space で押せる | ボタン | NFR10、AC3.1.8 |
| フォーカス | 取得開始・中断中・中断後で、フォーカスがボタンから外れない | ボタン | FR5.2、AC3.1.5 |
| 二度押し | 中断中に押しても何も起きない | ボタン | FR5.2、AC3.1.3 |
| 読み上げ（経過） | 経過の秒の変化では読み上げない | 経過 | FR4.6、AC2.1.7 |
| 読み上げ（注意） | 中断の注意が出たときに一度だけ読み上げる | 中断の注意 | FR5.11、AC4.1.6 |
| 色だけに頼らない | 中断の注意は warning のアイコンと文で伝える | 中断の注意 | FR5.11 |
| コントラスト | Cloudscape の primary ボタンと warning の Alert の既定の色を変えない（AA を満たす既定） | ボタン・注意 | — |
| 言語 | 英語と日本語の文言がそろっている | 3 か所すべて | NFR9、AC2.1.6 |
| 動き | 回る印は Cloudscape の既定（OS の「視差効果を減らす」に従う既定の振る舞いを変えない） | ボタン・状態表示 | — |

## 確かめ方

- 画面のテスト（Vitest）で、ボタンの文言・押せるか・フォーカスの位置、経過の表記、注意の文と role を確かめる。
- 手元で GUI を起動し、キーボードだけで取得と中断ができることを目で確かめる（team-practices の薄い一本の確認 3）。
