## Q3. 利用者から直接見えない要件（CI のカバレッジの下準備など）はどう扱いますか？

背景：CI でカバレッジを測る下準備（FR6）は、アプリの利用者ではなく作る人（開発者本人）のための作業です。呼び出しの量の抑え（FR2）とあきらめ方（FR3）は、利用者には「他の人を待たせない」「制限を受け続けても無駄に待たない」として間接的に見えます。

A. 下準備（FR6）は「作る人」のストーリーとして書く。FR2・FR3 は利用者から見える結果としてストーリーにする
B. 下準備（FR6）はストーリーにせず、技術的な作業として要件のまま扱う（対応表には理由を付けて「対象外」と書く）。FR2・FR3 は利用者から見える結果としてストーリーにする
C. FR2・FR3・FR6 のどれもストーリーにせず、要件のまま扱う
D. Not yet defined
X. Other (please specify)

[Answer]: B
