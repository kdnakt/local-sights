# Intent Statement — Logs Insights 互換のクエリ

## Problem Statement

いまの絞り込みは、メッセージに指定した文字列を含む行だけを残す仕組みで、条件を 1 つしか書けない。 [desc] [Q1]

いちばん困っているのは、条件を組み合わせられないことである（例：「ERROR を含み、かつ timeout を含まない」）。 [Q1]

この作業は、CloudWatch Logs Insights に似たクエリを書いて、ログを絞り込めるようにすることをねらう。今の部分一致の絞り込みを発展させる位置づけである。 [desc] [Q1]

Logs Insights のクエリの呼び出し（StartQuery など）は使えない。呼べるのは読み取りの 3 つ（DescribeLogGroups / DescribeLogStreams / GetLogEvents）だけなので、クエリそのものは手元で実行する。 [desc] [memory:M1]
