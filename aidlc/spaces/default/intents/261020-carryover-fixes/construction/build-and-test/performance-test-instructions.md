# 速さのテストの手引き（261020-carryover-fixes）

## 対象

NFR4：今の速さのテスト（既定で無視される 9 件）がすべて通り、261002 の NFR1・NFR2（10 万件 10 秒以内、100 万件 100 秒以内）を保つこと。この作業で新しい速さの目標は足していない。FR2.1 の読み止めで読む行が減ることは、速さではなく FR2.1 のテスト（後ろの壊れた行に気づかない＝読んでいない）で確かめる。

## 流し方

```bash
cargo test --release -p local-sights-core --lib -- --ignored
```

- リリースのビルドで流す（デバッグでは数字が出ない）。
- ほかの重い処理（ビルドや `cargo install`）と同時に流さない。時間の上限を持つテストのため、機械の混み具合で落ちることがある。
- AWS にはつながない（テストの中で作ったイベントを使う）。

## 合否

9 件がすべて通れば合格。1 件でも落ちたら、ほかの処理を止めてもう一度流し、それでも落ちれば不合格として test-results.md に書く（上限を緩めない）。
