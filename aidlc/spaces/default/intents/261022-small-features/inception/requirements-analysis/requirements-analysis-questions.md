## Q3. 書き出しの対象の行の数に、上限を置きますか？

- D. Not yet defined（設計で決める）

## Q6. CSV の文字コードと、Excel で開くときの配慮は？

Excel は BOM のない UTF-8 の CSV を文字化けして開くことがあります。Markdown はテキストとして貼る用途なので、この質問は CSV だけに関わります。

- A. UTF-8 に BOM を付ける（Excel でそのまま開ける。他のツールで BOM が邪魔になることは受け入れる）
- B. UTF-8 で BOM なし（コンソールのダウンロードと同じ。Excel では取り込みの操作が要る）
- C. 設計で決める（コンソールの CSV の実際の形を確かめてから合わせる）
- X. Other (please specify)

[Answer]: A

## Q7. メッセージを JSON とみなす条件は？

Lambda などのログは `2026-10-24T01:51:32Z  abc-123  INFO  {"a":1}` のように、前に時刻や ID が付いて JSON が後ろにあることがよくあります。

- A. メッセージ全体（前後の空白を除いて）が JSON のオブジェクトか配列のときだけ整形する。前に文字が付くものはそのまま
- B. メッセージの途中から JSON が始まるものも、前の部分はそのまま残して JSON の部分だけ整形する
- C. A に加えて、1 行のメッセージの末尾が JSON のときも整形する（前の部分と JSON の部分を分けて出す）
- D. Not yet defined（機能設計で決める）
- X. Other (please specify)

[Answer]: B
