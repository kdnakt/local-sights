# Rewrite the field names to those of your own log group before you use this file: latency
# stands for a JSON number field and status for a JSON text field. Rewrite the tolerances'

# more decimal places is not, plan.rs MAX_PERCENTILE_DECIMALS).

n01-num-aggregates	set	数：avg・sum・min・max・stddev（U2:BR2.3 の標本の stddev）	stats avg(latency), sum(latency), min(latency), max(latency), stddev(latency) by status	avg(latency)=decimal;sum(latency)=decimal;min(latency)=decimal;max(latency)=decimal;stddev(latency)=decimal
n02-pct	set	数：pct は最も近い順位（U2:BR2.2）	stats pct(latency, 50) as p50, pct(latency, 95) as p95, pct(latency, 99) as p99	p50=decimal;p95=decimal;p99=decimal
